Svelte `Editable` follows the thin parts + shorthand pattern (mirrors React and Solid). `Editable` is now a shorthand (`multiline`, `showControls`, `size`, `placeholder`, `classNames`) that renders the input or textarea, preview and cancel / submit buttons. Parts map 1:1 to Ark. **Breaking:** `Editable` (bare) is no longer the root; compound usage starts from `Editable.Root`.
