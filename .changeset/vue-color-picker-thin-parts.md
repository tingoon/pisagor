Vue `ColorPicker` follows the thin parts + shorthand pattern (mirrors React). `ColorPicker` is a shorthand (`clearable`, `variant`, `classNames`) with the default area / sliders / swatches content; every Ark part is exposed thinly (`Area`, `ChannelSlider`, `ChannelInput`, `EyeDropperTrigger`, `SwatchGroup`, …). **Breaking:** compound usage starts from `ColorPicker.Root`; `Field` was removed.
