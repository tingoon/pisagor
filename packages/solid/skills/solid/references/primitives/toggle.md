## When to use

- Stays pressed or released to turn a single option on or off, similar to a checkbox styled as a button.

## Import

```tsx
import { Toggle } from "@pisagor/solid/toggle";
```

Style with `@pisagor/recipes/toggle` — no app-level `tv()`.
