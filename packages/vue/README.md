# @pisagor/vue

Accessible Vue components on Ark UI and Tailwind CSS v4. Currently ships **Accordion** only.

```ts
import { Accordion } from "@pisagor/vue/accordion";
import "@pisagor/vue/styles";
```

Styles import `@pisagor/tokens` and scan `@pisagor/styles` recipes. There is no root barrel — import each component path.
