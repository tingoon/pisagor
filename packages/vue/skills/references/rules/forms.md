# Forms & inputs (Pisagor Vue)

- Prefer `@pisagor/vue-form` field helpers for labeled controls.
- Compose `Field` parts from `@pisagor/vue` for custom layouts (confirm names via MCP `get_component_source` / package exports).
- Public select surfaces: `Select`, `Autocomplete`, `Listbox` — not internal `Combobox` in apps.
- Use InputGroup parts for addons; follow MCP `get_example` for `input-group`.
- Class prop: `class`.
