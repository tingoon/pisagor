## When to use

- Displays large or interactive tabular datasets with grid behaviors.

## Import

```ts
import { DataGrid } from "@pisagor/vue/data-grid";
```

Style with `@pisagor/recipes/data-grid` — no app-level `tv()`.

Live examples below match `assets/examples/data-grid/`.
