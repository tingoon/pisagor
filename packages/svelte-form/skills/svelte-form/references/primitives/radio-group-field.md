## When to use

- Lets the user pick one option from a short list with an optional validation message.
- Mixing frameworks — this guide is **@pisagor/svelte-form** (not `@pisagor/svelte`).
- Treating shorthand as a composition root when `Foo.Root` is required.
- Calling `tv()` in app code — use `@pisagor/recipes`.

import { RadioGroupField } from "@pisagor/svelte-form/radio-group-field";
