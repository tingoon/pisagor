# Forms & inputs (Pisagor Svelte)

Labeled field components are not part of this skill. Prefer `@pisagor/svelte-form` — see that package’s skill (`packages/svelte-form/skills/svelte-form`). This file only covers `@pisagor/svelte` primitives used inside forms.

- Compose `Field` parts from `@pisagor/svelte` for custom layouts (confirm names via MCP `get_component_source` / package exports).
- Public select surfaces: `Select`, `Autocomplete`, `Listbox` — not internal `Combobox` in apps.
- Use InputGroup parts for addons; follow MCP `get_example` for `input-group`.
- Class prop: `class`.
