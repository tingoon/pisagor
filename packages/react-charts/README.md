# @pisagor/react-charts

Chart primitives for Pisagor React (Recharts wrappers).

```ts
import { Chart } from "@pisagor/react-charts";
import "@pisagor/react/styles";
import "@pisagor/react-charts/styles";
```

Peers: `react` ^19, `react-dom` ^19, `tailwindcss` ^4. Depends on `@pisagor/react` (uses `@pisagor/react/utils` for context).
