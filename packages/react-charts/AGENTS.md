# React Charts

Chart primitives for `@pisagor/react-charts` (Recharts wrappers). Stories under `Charts/…` in React Storybook.

```bash
turbo type-check --filter=@pisagor/react-charts
turbo dev --filter=react-storybook
```

Import from `@pisagor/react-charts`. Context helpers: `@pisagor/react/utils`. Do not author `tv()` here — use `@pisagor/recipes/chart`.
