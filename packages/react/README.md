# @pisagor/react

Accessible React components on Ark UI and Tailwind CSS v4.

```ts
import { Button } from "@pisagor/react/button";
import { Provider } from "@pisagor/react/provider";
import "@pisagor/react/styles";
```

There is no root `@pisagor/react` export. See the [root README](../../README.md) for peers, optional heavy components, and Tailwind setup.
