# Forms & inputs (Pisagor React)

Labeled field components are not part of this skill. Prefer `@pisagor/react-form` — see that package’s skill (`packages/react-form/skills/react-form`). This file only covers `@pisagor/react` primitives used inside forms.

- Compose `Field` parts from `@pisagor/react` for custom layouts (confirm names via MCP `get_component_source` / package exports).
- Public select surfaces: `Select`, `Autocomplete`, `Listbox` — not internal `Combobox` in apps.
- Use InputGroup parts for addons; follow MCP `get_example` for `input-group`.
- Class prop: `className`.
