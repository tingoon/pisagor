# @pisagor/recipes

Stable recipe import for Pisagor UI packages. Re-exports the default skin from `@pisagor/presets/pisagor`.

```ts
import { buttonRecipe } from "@pisagor/recipes";
```

To use another preset, alias this package to that skin (see `@pisagor/presets` README). Do not put block recipes here — they live in `apps/docs/src/recipes/blocks/`.
