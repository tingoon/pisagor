# Composition (Pisagor Astro)

- Astro components live under `@pisagor/astro` → `src/components/<name>/`.
- Prefer MCP `get_example` / `.astro` exports — do not assume React/Vue `Foo.Root` compound APIs for every Astro primitive.
- Prefer existing `@pisagor/astro` components over custom markup when the use case matches.
- Class prop is `class` (HTML), not `className`.
