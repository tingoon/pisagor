## When to use

- Shows that content or an action is still loading.

## Import

```ts
import { Spinner } from "@pisagor/astro/spinner";
```

Style with `@pisagor/recipes/spinner` — no app-level `tv()`.

Live examples below match `assets/examples/spinner/`.
