# Pisagor Astro Component Registry

Index for `@pisagor/astro`.

Use this skill only for **astro**. Sibling skills: `react`, `vue`, `solid`, `svelte`.

## Selection & Input
- **InputGroup** (`input-group`) — Composes an input with leading or trailing addons and actions. `./references/primitives/input-group/`

## Layout & Navigation
- **Breadcrumb** (`breadcrumb`) — Shows where the user is within a hierarchy and lets them jump back to earlier levels. `./references/primitives/breadcrumb/`

## Content & Display
- **Announcement** (`announcement`) — Draws attention to a short product or marketing message without blocking the rest of the interface. `./references/primitives/announcement/`
- **AspectRatio** (`aspect-ratio`) — Keeps media and embedded content at a consistent width-to-height ratio as the layout changes. `./references/primitives/aspect-ratio/`
- **Avatar** (`avatar`) — Shows a user or entity with an image or fallback initials. `./references/primitives/avatar/`
- **Badge** (`badge`) — Labels content with a compact status, category, or count so users can scan it quickly. `./references/primitives/badge/`
- **Card** (`card`) — Groups related content in a bordered surface with optional header and footer. `./references/primitives/card/`
- **DataList** (`data-list`) — Presents labeled values in a compact definition list. `./references/primitives/data-list/`
- **EmptyState** (`empty-state`) — Explains an empty view and offers a clear next action. `./references/primitives/empty-state/`
- **Format** (`format`) — Formats numbers, bytes, and relative times for display so values read naturally in the user locale. `./references/primitives/format/`
- **Frame** (`frame`) — Embeds external content in a framed viewport with a consistent chrome around it. `./references/primitives/frame/`
- **Highlight** (`highlight`) — Emphasizes matching words inside text so search results and queries are easier to spot. `./references/primitives/highlight/`
- **Item** (`item`) — Lays out a row of media, title, description, and actions for lists, menus, and pickers. `./references/primitives/item/`
- **Kbd** (`kbd`) — Displays keyboard shortcuts and key combinations. `./references/primitives/kbd/`
- **LinkBox** (`link-box`) — Makes an entire card or tile clickable while keeping nested buttons usable underneath. `./references/primitives/link-box/`
- **Prose** (`prose`) — Styles long-form HTML content with readable typography defaults. `./references/primitives/prose/`
- **Separator** (`separator`) — Visually divides related content into clear sections. `./references/primitives/separator/`
- **Stat** (`stat`) — Highlights a key metric with an optional label, description, and trend. `./references/primitives/stat/`
- **Surface** (`surface`) — Provides nested background surfaces that step through tonal levels. `./references/primitives/surface/`
- **Table** (`table`) — Displays tabular data with semantic table structure and styling. `./references/primitives/table/`
- **Timeline** (`timeline`) — Shows a sequence of events with indicators and supporting detail. `./references/primitives/timeline/`
- **VisuallyHidden** (`visually-hidden`) — Hides content visually while keeping it available to assistive technology. `./references/primitives/visually-hidden/`

## Feedback & Status
- **Alert** (`alert`) — Surfaces status, warning, or actionable feedback within page flow. `./references/primitives/alert/`
- **CircularProgress** (`circular-progress`) — Shows how far along a task is on a circular track, including indeterminate loading when the duration is unknown. `./references/primitives/circular-progress/`
- **Progress** (`progress`) — Shows how complete a task is along a track, including indeterminate loading when progress is unknown. `./references/primitives/progress/`
- **Skeleton** (`skeleton`) — Placeholders that reserve space while content is loading. `./references/primitives/skeleton/`
- **Spinner** (`spinner`) — Shows that content or an action is still loading. `./references/primitives/spinner/`
- **Status** (`status`) — Shows a compact status indicator for presence or state. `./references/primitives/status/`

## Actions
- **Button** (`button`) — Triggers an action or navigation with clear hierarchy and loading feedback. `./references/primitives/button/`
- **ButtonGroup** (`button-group`) — Groups related actions into a single segmented control. `./references/primitives/button-group/`

- **SkipNav** (`skip-nav`) — Lets keyboard users jump past repetitive navigation straight to the main content. `./references/primitives/skip-nav/`
