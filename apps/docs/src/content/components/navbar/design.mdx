Navbar is the top application bar that anchors brand, primary section links, search, and global actions. It orients people on every screen and holds the controls they expect to find without hunting.

Prefer Navbar for app chrome across authenticated product surfaces. Prefer <DocLink id="navigation-menu">Navigation Menu</DocLink> for marketing sites that need multi-column flyouts. Prefer <DocLink id="bottom-navigation">Bottom Navigation</DocLink> on phones when thumb reach matters more than a dense top bar. Prefer <DocLink id="menu">Menu</DocLink> for a persistent vertical list in a sidebar rather than horizontal top links.

## Best practices

**Keep primary destinations visible.** Show the sections people use daily; move rare links to <DocLink id="dropdown-menu">Dropdown Menu</DocLink> overflow.

**Reserve one prominent global action.** Search, Create, or Account should have a stable slot so muscle memory builds.

**Use translucent materials thoughtfully.** Let content scroll beneath a blurred bar when appropriate; solidify background when contrast drops.

**Collapse gracefully on narrow widths.** Hide labels into icons or a drawer before truncating the product name beyond recognition.

**Indicate where you are.** Style the active section link to match <DocLink id="menu">Menu</DocLink> active states elsewhere.

## Mobile

When the navbar competes with thumb reach, pair a slim top bar (title + back) with <DocLink id="bottom-navigation">Bottom Navigation</DocLink> for primary tabs.
