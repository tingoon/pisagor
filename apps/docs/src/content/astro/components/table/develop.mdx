## Import

```ts
import { Table } from "@pisagor/astro";
```

## Anatomy

```tsx
<Table>
  <Table.Caption />
  <Table.Header>
    <Table.Row>
      <Table.Head />
    </Table.Row>
  </Table.Header>
  <Table.Body>
    <Table.Row>
      <Table.Cell />
    </Table.Row>
  </Table.Body>
  <Table.Footer />
</Table>
```

### Sizes

Use `size` to pick the sm, md or lg scale. `md` is the default. Astro parts cannot read the root size, so pass the same `size` to `Table.Head` and `Table.Cell`.
