## Import

```ts
import { Frame } from "@pisagor/astro";
```

## Anatomy

```tsx
<Frame>
  <Frame.Header>
    <Frame.Title />
    <Frame.Description />
  </Frame.Header>
  <Frame.Panel />
  <Frame.Footer />
</Frame>
```
