Separator divides sections of content with a subtle line or gap so grouped information is easier to scan. It provides structure without shouting — unlike headings, it does not introduce a new topic name.

Prefer Separator between related blocks in the same view; prefer headings when the break needs a label people should remember. Use horizontal separators between stacked sections and vertical separators between columns in toolbars or split rows.

## Best practices

**Use separators for rhythm, not decoration.** Add a line when grouping changes; skip extra lines that create visual noise.

**Match orientation to layout.** Horizontal between stacked blocks; vertical between inline groups in a row or toolbar.

**Do not replace semantic structure.** Separators are visual; still use headings, lists, and landmarks for accessibility.

**Keep contrast subtle.** Separators should recede; body text and primary actions remain the focal layer.

**Pair with spacing.** Margin around the separator often matters as much as the line itself for readable grouping.

## Menus and lists

In menus, separators group related commands without implying order. Avoid separating every single item — that defeats the purpose of grouping.
