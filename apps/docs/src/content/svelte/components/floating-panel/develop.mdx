## Import

```ts
import { FloatingPanel } from "@pisagor/svelte";
```

## Anatomy

```tsx
<FloatingPanel />
```

The shorthand renders the drag header, stage controls (`showStageControls`), close button (`showCloseButton`), scrollable body (`scrollFade`), footer and resize handles (`resizable`).
