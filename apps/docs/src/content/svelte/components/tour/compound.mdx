## Anatomy

```svelte
<Tour.Root {tour}>
  <Tour.Backdrop />
  <Tour.Spotlight />
  <Tour.Positioner>
    <Tour.Content>
      <Tour.Arrow>
        <Tour.ArrowTip />
      </Tour.Arrow>
      <Tour.Header>
        <Tour.ProgressText />
        <Tour.Title />
        <Tour.Description />
      </Tour.Header>
      <Tour.Body />
      <Tour.Actions>
        {#snippet children(actions)}
          <Tour.Control>
            {#each actions() as action (action.label)}
              <Tour.ActionTrigger {action} />
            {/each}
          </Tour.Control>
        {/snippet}
      </Tour.Actions>
      <Tour.CloseTrigger />
    </Tour.Content>
  </Tour.Positioner>
</Tour.Root>
```

Create the tour with `useTour` and start it with `tour().start()`. Wrap the overlay parts in `Portal`.
