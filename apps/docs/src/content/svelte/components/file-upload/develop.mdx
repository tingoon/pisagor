## Import

```ts
import { FileUpload } from "@pisagor/svelte";
```

## Anatomy

```tsx
<FileUpload description="or" helper="Up to 2 files." title="Drop files here">
  {#snippet trigger(props)}
    <Button {...props()}>Browse files</Button>
  {/snippet}
</FileUpload>
```

The shorthand renders the dropzone (`icon`, `title`, `description`, `trigger`, `helper`), an optional `label` and `clearTrigger`, and the accepted / rejected file list (`showList`). Set `dropzone={false}` for a trigger-only picker. Compose `FileUpload.Root` and its parts for custom layouts (see Compound).
