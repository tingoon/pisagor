## Import

```ts
import { Collapsible } from "@pisagor/svelte";
```

## Anatomy

```tsx
<Collapsible>
  <Collapsible.Trigger>
    <Collapsible.Indicator />
  </Collapsible.Trigger>
  <Collapsible.Content />
</Collapsible>
```
