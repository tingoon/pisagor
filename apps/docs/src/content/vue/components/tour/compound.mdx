## Anatomy

```vue
<script setup lang="ts">
const tour = useTour({ steps });
</script>

<Tour.Root :tour="tour">
  <Tour.Backdrop />
  <Tour.Spotlight />
  <Tour.Positioner>
    <Tour.Content>
      <Tour.Arrow>
        <Tour.ArrowTip />
      </Tour.Arrow>
      <Tour.Header>
        <Tour.ProgressText />
        <Tour.Title />
        <Tour.Description />
      </Tour.Header>
      <Tour.Body />
      <Tour.Control>
        <Tour.ActionTrigger
          v-for="action in tour.step?.actions"
          :key="action.label"
          :action="action"
        />
      </Tour.Control>
      <Tour.CloseTrigger />
    </Tour.Content>
  </Tour.Positioner>
</Tour.Root>
```

Create the tour with `useTour` and start it with `tour.start()`. Wrap the overlay parts in `Teleport`.
