## Anatomy

```vue
<TagsInput.Root>
  <TagsInput.Label />
  <TagsInput.Control>
    <TagsInput.Context v-slot="{ value }">
      <TagsInput.Item v-for="(tag, index) in value" :key="tag" :index="index" :value="tag">
        <TagsInput.ItemPreview>
          <TagsInput.ItemText />
          <TagsInput.ItemDeleteTrigger />
        </TagsInput.ItemPreview>
        <TagsInput.ItemInput />
      </TagsInput.Item>
    </TagsInput.Context>
    <TagsInput.Input />
    <TagsInput.ClearTrigger />
  </TagsInput.Control>
</TagsInput.Root>
```

Parts map 1:1 to Ark. Use `as-child` to render `Control` as an `InputGroup` and pass your own delete/clear icons; the `TagsInput` shorthand does this for you.
