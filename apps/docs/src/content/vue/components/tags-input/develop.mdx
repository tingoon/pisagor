## Import

```ts
import { TagsInput } from "@pisagor/vue";
```

## Anatomy

```vue
<TagsInput>
  <TagsInput.Context>
    {({ value }) => value.map((tag, index) => <TagsInput.Item />)}
  </TagsInput.Context>
</TagsInput>
```
