## Import

```ts
import { Sheet } from "@pisagor/vue";
```

## Anatomy

```vue
<Sheet>
  <Sheet.Trigger />
  <Sheet.Content>
    <Sheet.Header>
      <Sheet.Title />
      <Sheet.Description />
    </Sheet.Header>
    <Sheet.Body />
    <Sheet.Footer>
      <Sheet.CloseTrigger />
    </Sheet.Footer>
  </Sheet.Content>
</Sheet>
```
