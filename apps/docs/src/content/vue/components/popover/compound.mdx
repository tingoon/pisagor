## Anatomy

```vue
<Popover>
  <Popover.Trigger />
  <Popover.Anchor />
  <Popover.Content>
    <Popover.Header /> {/* or Title + Description */}
    <Popover.Body />
    <Popover.Footer />
    <Popover.CloseTrigger />
  </Popover.Content>
</Popover>
```

`Positioner` and `Arrow` are available when you need custom positioning chrome.
