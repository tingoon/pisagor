## Anatomy

```vue
<ContextMenu.Root>
  <ContextMenu.ContextTrigger />
  <ContextMenu.Positioner>
    <ContextMenu.Content>
      <ContextMenu.ItemGroup>
        <ContextMenu.ItemGroupLabel />
        <ContextMenu.Item>
          <ContextMenu.Shortcut />
        </ContextMenu.Item>
      </ContextMenu.ItemGroup>
      <ContextMenu.CheckboxItem>
        <ContextMenu.ItemIndicator />
        <ContextMenu.ItemText />
      </ContextMenu.CheckboxItem>
      <ContextMenu.RadioItemGroup>
        <ContextMenu.RadioItem>
          <ContextMenu.ItemIndicator />
          <ContextMenu.ItemText />
        </ContextMenu.RadioItem>
      </ContextMenu.RadioItemGroup>
      <ContextMenu.Separator />
      <ContextMenu.Sub>
        <ContextMenu.TriggerItem>
          <ContextMenu.Indicator />
        </ContextMenu.TriggerItem>
        <ContextMenu.Positioner>
          <ContextMenu.Content />
        </ContextMenu.Positioner>
      </ContextMenu.Sub>
    </ContextMenu.Content>
  </ContextMenu.Positioner>
</ContextMenu.Root>
```

Wrap each `Positioner` in `Teleport`. Icons are not built in: pass the check icon to `ItemIndicator` and the caret to `Indicator`.
