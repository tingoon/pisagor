## Import

```ts
import { Command } from "@pisagor/vue";
```

## Anatomy

```vue
<Command>
  <Command.Input />
  <Command.Content>
    <Command.Empty />
    <Command.List>
      <Command.ItemGroup>
        <Command.Item>
          <Command.Shortcut />
        </Command.Item>
        <Command.Separator />
      </Command.ItemGroup>
    </Command.List>
  </Command.Content>
</Command>
```
