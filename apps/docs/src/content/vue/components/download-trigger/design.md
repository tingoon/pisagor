Download Trigger starts a file download when activated so people can save content without leaving the page. It turns export and asset retrieval into an explicit, predictable action.

Prefer Download Trigger when the browser should save a file from a known URL or generated blob. Prefer navigation to a detail page when people need to preview before saving.

## Best practices

**Label with the outcome.** Use Download, Export PDF, or Save report so people know what file they will receive.

**Set expectations on size and type.** When downloads are large or slow, note format and approximate size, and show progress if generation takes time.

**Use meaningful filenames.** Suggest a default name that includes context and date rather than opaque identifiers.

**Do not surprise with multiple files.** If one action creates several downloads, explain that upfront or zip assets into one file.

**Respect permissions and errors.** Disable or explain when the user lacks access; surface failures with a retry path instead of silent no-ops.

## Security

Only trigger downloads from trusted sources generated by your application. Avoid passing unsanitized user input directly into download URLs.
