## Import

```ts
import { ActionBar } from "@pisagor/vue";
```

## Anatomy

```vue
<ActionBar>
  <ActionBar.Trigger />
  <ActionBar.Content>
    <ActionBar.Value />
    <ActionBar.Separator />
    <ActionBar.Body />
    <ActionBar.Close />
  </ActionBar.Content>
</ActionBar>
```
