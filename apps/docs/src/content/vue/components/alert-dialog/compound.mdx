## Anatomy

```vue
<AlertDialog.Root>
  <AlertDialog.Trigger />
  <AlertDialog.Backdrop />
  <AlertDialog.Positioner>
    <AlertDialog.Content>
      <AlertDialog.Header>
        <AlertDialog.Title />
        <AlertDialog.Description />
      </AlertDialog.Header>
      <AlertDialog.Body />
      <AlertDialog.Footer>
        <AlertDialog.Cancel />
        <AlertDialog.Action />
      </AlertDialog.Footer>
    </AlertDialog.Content>
  </AlertDialog.Positioner>
</AlertDialog.Root>
```
