## Import

```tsx
import { Steps } from "@pisagor/react";
```

## Anatomy

```tsx
<Steps items={[{ title: "Account", content: "…" }]} completedContent="Done" />
```

The shorthand derives `count` from `items` and renders the list, each step's content, the completed content, and localized back/next buttons (`showControls={false}` hides them). Compose `Steps.Root` and its parts directly for custom layouts (see Compound).
