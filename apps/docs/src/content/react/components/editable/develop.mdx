## Import

```tsx
import { Editable } from "@pisagor/react";
```

## Anatomy

```tsx
<Editable placeholder="Click to edit" />
```

The shorthand renders `Area` with an `Input` (or `Textarea` with `multiline`) and `Preview`, plus cancel/submit buttons unless `showControls={false}`. Compose `Editable.Root` and its parts directly for custom layouts (see Compound).
