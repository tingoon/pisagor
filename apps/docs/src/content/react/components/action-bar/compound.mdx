## Anatomy

```tsx
<ActionBar.Root>
  <ActionBar.Trigger />
  <ActionBar.Positioner>
    <ActionBar.Content>
      <ActionBar.Value />
      <ActionBar.Separator />
      <ActionBar.Body />
      <ActionBar.Close />
    </ActionBar.Content>
  </ActionBar.Positioner>
</ActionBar.Root>
```
