## Anatomy

```tsx
<Pagination.Root>
  <Pagination.PrevTrigger />
  <Pagination.Context>
    {({ pages }) =>
      pages.map((page) =>
        page.type === "page" ? <Pagination.Item /> : <Pagination.Ellipsis />,
      )
    }
  </Pagination.Context>
  <Pagination.NextTrigger />
</Pagination.Root>
```

Parts map 1:1 to Ark (`ItemLink` is a Pisagor helper for URL-driven pages). Pass your own buttons with `asChild`; the `Pagination` shorthand renders the previous/next buttons and page list for you.
