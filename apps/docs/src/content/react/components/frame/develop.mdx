## Import

```tsx
import { Frame } from "@pisagor/react";
```

## Anatomy

```tsx
<Frame>
  <Frame.Header>
    <Frame.Title />
    <Frame.Description />
  </Frame.Header>
  <Frame.Panel />
  <Frame.Footer />
</Frame>
```
