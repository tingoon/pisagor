## Anatomy

```tsx
<Breadcrumb.Root>
  <Breadcrumb.List>
    <Breadcrumb.Item>
      <Breadcrumb.Link />
    </Breadcrumb.Item>
    <Breadcrumb.Separator />
    <Breadcrumb.Item>
      <Breadcrumb.Page />
    </Breadcrumb.Item>
  </Breadcrumb.List>
</Breadcrumb.Root>
```

Parts render no icons: put your separator icon (or text) in `Separator` and your dots icon in `Ellipsis`. The `Breadcrumb` shorthand uses a caret separator by default (`separator`).
