## Import

```tsx
import { Collapsible } from "@pisagor/react";
```

## Anatomy

```tsx
<Collapsible trigger="Details">Content</Collapsible>
```

The shorthand renders `Trigger` with the label and caret `Indicator`, then `Content` > `Body` with children. Compose `Collapsible.Root` and its parts directly for custom triggers (see Compound).
