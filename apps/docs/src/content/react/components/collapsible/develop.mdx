## Import

```tsx
import { Collapsible } from "@pisagor/react";
```

## Anatomy

```tsx
<Collapsible>
  <Collapsible.Trigger>
    <Collapsible.Indicator />
  </Collapsible.Trigger>
  <Collapsible.Content />
</Collapsible>
```
