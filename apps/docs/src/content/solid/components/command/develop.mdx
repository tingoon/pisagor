## Import

```tsx
import { Command } from "@pisagor/solid";
```

## Anatomy

```tsx
<Command>
  <Command.Input />
  <Command.Content>
    <Command.Empty />
    <Command.List>
      <Command.ItemGroup>
        <Command.Item>
          <Command.Shortcut />
        </Command.Item>
        <Command.Separator />
      </Command.ItemGroup>
    </Command.List>
  </Command.Content>
</Command>
```
