## Anatomy

```tsx
<Command.Root collection={collection}>
  <Command.Control>
    <Command.Input />
  </Command.Control>
  <Command.Content>
    <Command.Empty />
    <Command.List>
      <Command.ItemGroup>
        <Command.ItemGroupLabel />
        <Command.Item>
          <Command.Shortcut />
        </Command.Item>
        <Command.Separator />
      </Command.ItemGroup>
    </Command.List>
  </Command.Content>
  <Command.Footer />
</Command.Root>
```

`Command.Dialog` wraps any palette in a dialog (`trigger`, `open`, `onOpenChange`, hidden `title` / `description`).
