### Messages

Pass `locale` (BCP 47, default `en-US`), an optional `dir` (derived from `locale` when omitted) and `messages` to override built-in UI messages (aria labels, empty states, button text) by key. Every key has an English default in `defaultMessages` from `@pisagor/utils`; the `messages` you pass are merged over it and over any parent `Provider`, so a partial object is enough. Keys are typed as `MessageKey`, so they autocomplete. Use `Provider.Locale` to change these for a subtree only.

### useLocale

`useLocale()` returns `{ locale, dir, messages, m }`: the BCP 47 `locale`, the text `dir` (`"ltr"` or `"rtl"`), every resolved UI message in `messages`, and `m(key, override?)`, which returns `override` when it is not `null`/`undefined`, otherwise `messages[key]`. Call it during component setup. `m` and the `locale` / `dir` / `messages` getters read the current `Provider` values, so they stay reactive inside JSX (don't destructure `locale`, `dir` or `messages` outside a tracked scope). Use `formatMessage(m(key), values)` from `@pisagor/utils` for messages with placeholders.

```tsx
import { useLocale } from "@pisagor/solid";

export function LoadingLabel(props: { ariaLabel?: string }) {
  const { m } = useLocale();
  return <span aria-label={m("spinner.loading", props.ariaLabel)} />;
}
```
