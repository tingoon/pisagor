## Anatomy

```tsx
<NumberInput.Root>
  <NumberInput.Scrubber>
    <NumberInput.Label />
  </NumberInput.Scrubber>
  <NumberInput.Control>
    <NumberInput.DecrementTrigger />
    <NumberInput.Input />
    <NumberInput.ClearTrigger />
    <NumberInput.IncrementTrigger />
  </NumberInput.Control>
</NumberInput.Root>
```

Parts map 1:1 to Ark (`ClearTrigger` is a Pisagor helper). Pass your own button and icon to the triggers with `asChild`; the `NumberInput` shorthand does this for you.
