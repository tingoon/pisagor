## Import

```tsx
import { Timer } from "@pisagor/solid";
```

## Anatomy

```tsx
<Timer autoStart units={["minutes", "seconds"]} showControls />
```

The shorthand renders each unit with a localized label and separators, plus play/pause and reset buttons with `showControls`. Compose `Timer.Root` and its parts directly for custom layouts (see Compound).
