## Anatomy

```tsx
const tour = useTour({ steps });

<Tour.Root tour={tour}>
  <Tour.Backdrop />
  <Tour.Spotlight />
  <Tour.Positioner>
    <Tour.Content>
      <Tour.Arrow>
        <Tour.ArrowTip />
      </Tour.Arrow>
      <Tour.Header>
        <Tour.ProgressText />
        <Tour.Title />
        <Tour.Description />
      </Tour.Header>
      <Tour.Body />
      <Tour.Actions>
        {(actions) => (
          <Tour.Control>
            {actions.map((action) => (
              <Tour.ActionTrigger action={action} key={action.label} />
            ))}
          </Tour.Control>
        )}
      </Tour.Actions>
      <Tour.CloseTrigger />
    </Tour.Content>
  </Tour.Positioner>
</Tour.Root>;
```

Create the tour with `useTour` and start it with `tour.start()`. Wrap the overlay parts in `Portal`.
