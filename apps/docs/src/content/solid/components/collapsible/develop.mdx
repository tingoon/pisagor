## Import

```tsx
import { Collapsible } from "@pisagor/solid";
```

## Anatomy

```tsx
<Collapsible>
  <Collapsible.Trigger>
    <Collapsible.Indicator />
  </Collapsible.Trigger>
  <Collapsible.Content />
</Collapsible>
```
