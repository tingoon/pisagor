## Import

```tsx
import { NavigationMenu } from "@pisagor/solid";
```

## Anatomy

```tsx
<NavigationMenu>
  <NavigationMenu.List>
    <NavigationMenu.Item>
      <NavigationMenu.Link />
    </NavigationMenu.Item>
  </NavigationMenu.List>
</NavigationMenu>
```
